# Intruguard

**Intruguard** is an AI-powered Intrusion Detection System (IDS) designed to detect anomalous network activity and identify potential cyber threats using machine learning.

The system is trained and evaluated on network traffic datasets from **CICIDS**, using feature extraction, anomaly detection, and classification techniques to distinguish between normal and malicious network activity.

## Features

* Network traffic preprocessing and feature extraction
* Machine learning-based anomaly detection
* Attack classification
* CICIDS dataset support
* Modular data processing pipeline
* Threat detection and alerting
* Designed for real-time intrusion detection

## Tech Stack

* **Python**
* **Scikit-learn**
* **Pandas**
* **NumPy**
* **Matplotlib / Seaborn**
* **CICIDS Datasets**

## How It Works

```text
Network Traffic
      ↓
Data Preprocessing
      ↓
Feature Extraction
      ↓
Anomaly Detection
      ↓
Attack Classification
      ↓
Threat Alert
```

## Dataset

The project uses the **CICIDS datasets**, which contain realistic network traffic and multiple types of cyberattacks for training and evaluating intrusion detection models.
